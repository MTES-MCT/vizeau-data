# vizeau-data

Recueil d'outils de transformation de données liés au projet Viz'eau.

## Outils

- [`pmtiles_generator`](pmtiles_generator/README.md) — génère des fichiers PMTiles multi-couches à partir du Registre Parcellaire Graphique (RPG).
- [`gpkg_to_parquet`](gpkg_to_parquet/README.md) — convertit un GeoPackage des Aires d'Alimentation de Captage en GeoParquet trié par courbe de Hilbert.
